    Laboratory-Developed Tests¶

    Laboratory-developed tests (LDTs) are in vitro diagnostic tests designed, developed, and validated within a single laboratory, typically for use only within that laboratory.

    Definition and Scope¶

    An LDT is any test that: - Is not manufactured or sold as a kit - Is developed or modified by a laboratory - Is intended for clinical use - Is performed within the developing laboratory - May be subject to FDA oversight (evolving policy)

    When LDTs Are Used¶

    LDTs are developed when: - No FDA-approved/cleared test exists - Existing FDA-approved tests don't meet clinical needs - Testing rare conditions (orphan diseases) - Developing novel testing methodologies - Adapting tests for new specimen types - Creating multiplex or panel tests - Responding to emerging pathogens - Offering specialized or niche testing

    Types of LDTs¶

    Molecular Diagnostic Tests¶

    • Custom PCR assays
    • In-house sequencing panels
    • Gene expression assays
    • Genotyping tests
    • Rare variant detection

    Mass Spectrometry Applications¶

    • MALDI-TOF identifications
    • Custom metabolomic panels
    • Proteomic assays
    • Drug level monitoring

    Biochemical Tests¶

    • Enzyme activity assays
    • Custom analyte measurements
    • Novel biomarker detection
    • Modified biochemical methods

    Histopathology Tests¶

    • Specialized stains
    • Immunohistochemistry panels
    • In situ hybridization assays
    • Molecular pathology assays

    Next-Generation Sequencing¶

    • Custom gene panels
    • Whole exome/genome analysis
    • Transcriptome sequencing
    • Metagenomic sequencing

    LDT Development Process¶

    Phase 1: Feasibility Assessment¶

    Questions: 1. Is there an unmet clinical need? 2. Does an FDA-approved test exist? 3. Can the need be met with existing tests? 4. What are the regulatory requirements? 5. What are the resource requirements?

    Deliverables: - Feasibility report - Clinical justification - Regulatory pathway assessment - Resource and cost analysis

    Phase 2: Method Development¶

    Activities: - Literature review and research - Protocol development - Reagent selection and optimization - Instrument configuration - Software development (if needed) - Preliminary testing

    Considerations: - Scientific validity - Analytical performance - Clinical utility - Regulatory compliance

    Phase 3: Analytical Validation¶

    Required Studies: - Accuracy (method comparison) - Precision (within-run, between-run) - Analytical sensitivity (LoD, LoQ) - Analytical specificity (interference, cross-reactivity) - Reportable range (linearity) - Reference interval (establishment)

    Documentation: - Validation protocol - Raw data - Statistical analysis - Validation report - Approvals

    Phase 4: Clinical Validation (if applicable)¶

    Purpose: Establish clinical performance and utility

    Studies: - Diagnostic sensitivity and specificity - ROC analysis - Predictive values - Clinical correlation - Impact on patient care

    Phase 5: Implementation¶

    Activities: - Update laboratory procedures - Train all staff - Establish QC program - Set up reporting - Implement result interpretation - Begin patient testing

    Phase 6: Ongoing Monitoring¶

    Activities: - Daily quality control - Proficiency testing (if available) - Ongoing verification - Performance monitoring - Periodic revalidation - Change control

    Regulatory Landscape¶

    CLIA Requirements (42 CFR §493.1253)¶

    • Must validate all performance characteristics
    • Must maintain comprehensive documentation
    • Must establish ongoing QC program
    • Must have qualified personnel
    • Subject to CLIA inspection

    FDA Oversight (Evolving)¶

    • Historical Policy: Enforcement discretion for most LDTs
    • Current Policy (2024): Increased oversight
    • High-risk LDTs require FDA review
    • Phase-in period for existing LDTs
    • Pre-market notification required
    • Quality system requirements
    • Adverse event reporting

    Risk-Based Classification: - High-Risk: Same as similar FDA-cleared devices - Moderate-Risk: Reduced requirements - Low-Risk: Minimal oversight

    State Regulations¶

    • Some states require additional approval
    • NY State Department of Health (CLEP) approval
    • California requirements for certain tests
    • Other state-specific requirements

    Payer Requirements¶

    • Medicare coverage requires clinical validity
    • Private payers may require evidence
    • CPT code assignment may be challenging
    • Reimbursement varies by test

    Quality Management for LDTs¶

    Documentation Requirements¶

    • Complete method description
    • Validation protocol and report
    • Standard operating procedures
    • QC procedures and acceptance criteria
    • Result reporting and interpretation
    • Personnel training records
    • Change control procedures

    Quality Control¶

    • Daily QC with appropriate controls
    • Multi-level QC for quantitative tests
    • Include negative controls for qualitative tests
    • Document all QC results
    • Investigate out-of-control situations
    • Maintain QC records

    Proficiency Testing¶

    • Enroll in PT program if available
    • If PT not available, establish alternative assessment
    • Document alternative assessment procedures
    • Participate in inter-laboratory comparisons

    Ongoing Verification¶

    • Periodic verification of performance
    • Compare to reference methods
    • Monitor trends over time
    • Revalidate after significant changes

    Change Control¶

    • Document all changes to method
    • Assess impact on performance
    • Perform bridging studies if needed
    • Update documentation
    • Retrain staff

    2. Read quality metrics
    3. Adapter contamination

    4. Coverage analysis

    5. Alignment and Mapping

    6. Reference genome validation
    7. Mapping efficiency

    8. Duplicate removal

    9. Variant Calling

    10. Sensitivity validation
    11. Specificity validation

    12. Variant confirmation

    13. Annotation and Interpretation

    14. Database validation
    15. Clinical significance assessment
    16. Report generation

    Validation Requirements¶

    • Analytical sensitivity (limit of detection)
    • Analytical specificity (false positive rate)
    • Precision (repeatability, reproducibility)
    • Accuracy (comparison to orthogonal methods)
    • Reference database validation
    • Performance at different coverage levels

    Challenges and Considerations¶

    Resource Requirements¶

    • Specialized expertise required
    • Significant time investment
    • Ongoing maintenance costs
    • Equipment and reagent costs

    Regulatory Complexity¶

    • Evolving FDA policy
    • State-specific requirements
    • Payer coverage challenges
    • CPT coding issues

    Quality Management¶

    • Comprehensive documentation required
    • Robust QC program needed
    • Ongoing monitoring essential
    • Change control critical

    Clinical Validation¶

    • Establishing clinical utility
    • Demonstrating value
    • Gaining acceptance
    • Standardization challenges

    Sustainability¶

    • Long-term support requirements
    • Expertise retention
    • Technology updates
    • Revalidation requirements

    Revalidation Requirements¶

    Revalidation is required when: - Significant changes to method - New software version - New reagent lot with different performance - New instrument platform - Changes to critical reagents - Clinical need changes - New regulatory requirements
