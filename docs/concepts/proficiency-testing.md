# Proficiency Testing

**Proficiency testing (PT)** is an external quality assessment program where laboratories test unknown samples and submit results for evaluation against peer groups. CLIA requires PT participation for most non-waived tests.

## CLIA Requirements

- Enroll in CMS-approved PT program
- Test PT samples as routine patient specimens
- Achieve satisfactory performance (≥80%)
- Do not share PT results with other laboratories
- Investigate and document unsatisfactory results
- Three consecutive unsatisfactory results = sanctions

## PT Process

1. Receive unknown samples from PT provider
2. Test samples using routine workflow
3. Submit results within specified timeframe
4. Receive evaluation against peer group
5. Investigate any failures
6. Document corrective actions
