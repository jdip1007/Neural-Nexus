# ADOS and IQ Circularity

**Definition:** The circular relationship between the Autism Diagnostic Observation Schedule (ADOS) and IQ, where ADOS calibration is IQ-dependent and IQ measurement is ASD-diagnostic-dependent, compromising the independence of both measures.

## Mechanism

The ADOS (the gold-standard ASD diagnostic instrument) has two properties that create circularity with IQ:

1. **IQ-stratified algorithms:** ADOS-2 uses different algorithms for individuals with and without language impairment (roughly mapping to IQ). The "Toddler Module" and "Module 1" target pre-verbal/minimally verbal individuals, while Modules 3-4 target fluent speakers. Each module has different cutoffs.

2. **IQ-sensitive items:** ADOS items assess imaginative play, social reciprocity, and communication — all influenced by cognitive level independent of ASD severity. A lower-IQ individual may score higher on ADOS social-communication items for reasons partly driven by cognitive rather than autistic impairment.

This means:
- ADOS classification is influenced by IQ → IQ is often assessed alongside ADOS → IQ assessment is influenced by ASD symptoms → which ADOS is measuring

## Clinical Significance

- Neither ADOS scores nor IQ scores can be treated as "ground truth" in ASD assessment — both are contaminated by the other
- Diagnosis should not rest on ADOS alone; comprehensive assessment requires multiple data sources
- The circularity is strongest at the IQ boundaries where ADOS module transitions occur

## Therapeutic Approaches

- Use ADOS as one component of multi-method assessment (interviews, observation, developmental history, adaptive functioning)
- Be cautious at module boundaries (e.g., Module 2 vs 3 transition)
- Consider whether an ADOS score reflects ASD severity, cognitive level, or both
