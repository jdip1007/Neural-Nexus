# Respiratory Virus Testing

## Overview

Clinical laboratory testing for detection and quantification of respiratory viruses in patient samples.

## Common Targets

- **Influenza viruses:** Influenza A, Influenza B, H1N1pdm
- **Respiratory Syncytial Virus (RSV):** RSV A, RSV B
- **Human Metapneumovirus (hMPV):** hMPV A, hMPV B
- **Parainfluenza viruses:** PIV-1, PIV-2, PIV-3, PIV-4
- **Adenovirus:** Multiple serotypes
- **Rhinovirus/Enterovirus:** Common cold viruses
- **SARS-CoV-2:** COVID-19 virus

## Sample Types

- Nasopharyngeal swabs
- Oropharyngeal swabs
- Nasal swabs
- Bronchoalveolar lavage (BAL)
- Tracheal aspirates
- Sputum

## Detection Methods

- **qPCR:** Real-time PCR (most common)
- **Multiplex PCR:** Simultaneous detection of multiple viruses
- **Antigen testing:** Rapid point-of-care tests
- **Viral culture:** Traditional method, slower turnaround
