# ASD and IQ Interplay

**Definition:** The reciprocal influence between autism spectrum disorder diagnostics and intelligence quotient measurement, where each compromises the validity of the other.

## Mechanism

Standard IQ tests (Wechsler scales, etc.) require abilities that overlap with ASD core deficits — verbal comprehension, processing speed, social understanding, cognitive flexibility. This means IQ scores in ASD may underestimate true cognitive capacity. Conversely, ASD diagnostic instruments (ADOS) are calibrated differently across IQ levels, meaning IQ influences diagnostic scores. This creates a circularity: the instrument used to diagnose ASD is affected by the same cognitive traits it aims to measure independently.

## Key Dynamics

1. **Test overlap:** IQ subtests demand social reasoning and flexible thinking — the very domains impaired in ASD
2. **Instrument calibration:** ADOS has IQ-stratified algorithms; different cutoffs apply at different IQ levels
3. **Score depression:** ASD individuals may score lower on IQ tests due to test format demands rather than true cognitive limitation
4. **Diagnostic threshold shift:** As IQ increases, more ASD symptoms are needed to cross diagnostic threshold (compensation effect)

## Clinical Significance

- IQ scores in ASD should be interpreted cautiously, not as fixed cognitive endpoints
- The ADOS-IQ circularity means neither measure is truly "independent" in ASD assessment
- Misinterpretation of IQ can lead to inappropriate support allocation (over-supporting or under-supporting)

## Therapeutic Approaches

- Use IQ tests with reduced social/verbal demands (e.g., Raven's Progressive Matrices) for more valid estimation
- Apply ADOS with awareness of IQ-related calibration effects
- Consider adaptive functioning alongside IQ for support planning
