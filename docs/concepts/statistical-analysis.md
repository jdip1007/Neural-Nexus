# Statistical Analysis

## Definition

**Statistical analysis** in the clinical laboratory encompasses the quantitative methods used to evaluate, monitor, and validate the performance of laboratory tests. These methods characterize accuracy, precision, bias, reference intervals, and [diagnostic-accuracy](concepts/diagnostic-accuracy.md), forming the analytical backbone of [method-performance](concepts/accreditation/method-performance.md) evaluation and routine [quality-control](concepts/quality-control.md).

## Key Points

- **Precision** (repeatability/reproducibility) and **accuracy** (closeness to true value) are the fundamental performance metrics quantified statistically.
- **Regression analysis** (e.g., Deming, Passing-Bablok) compares a new method against a reference method, quantifying bias and proportional error.
- **Bland-Altman analysis** assesses agreement between two methods, plotting differences against means.
- **ROC analysis** evaluates [diagnostic-accuracy](concepts/diagnostic-accuracy.md), quantifying sensitivity and specificity across decision thresholds (AUC).
- Statistical methods underpin [laboratory-verification](concepts/accreditation/laboratory-verification.md) and [laboratory-validation](concepts/accreditation/laboratory-validation.md) studies, including reference interval establishment and determination of analytical measurement range.
- **Control chart statistics** (Levey-Jennings, Westgard rules) apply these principles to routine QC monitoring.

## Common Methods

| Method | Application |
|---|---|
| Descriptive statistics | Mean, SD, CV for QC data |
| Regression (Deming/Passing-Bablok) | Method comparison |
| Bland-Altman | Method agreement |
| ROC / AUC | [diagnostic-accuracy](concepts/diagnostic-accuracy.md) |
| ANOVA / components of variance | Precision evaluation |
| Tolerance / prediction intervals | Reference range estimation |

## Relationship to Quality Systems

Statistical analysis is the quantitative engine connecting several laboratory quality activities: it provides the evidence for [method-performance](concepts/accreditation/method-performance.md) claims, the data for [quality-control](concepts/quality-control.md) decisions, and the analytical foundation for [laboratory-verification](concepts/accreditation/laboratory-verification.md) and [laboratory-validation](concepts/accreditation/laboratory-validation.md) protocols.
