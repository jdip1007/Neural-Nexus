# Statistical Analysis

## Definition

**Statistical analysis** in the clinical laboratory encompasses the quantitative methods used to evaluate, monitor, and validate the performance of laboratory tests. These methods characterize accuracy, precision, bias, reference intervals, and [[diagnostic-accuracy]], forming the analytical backbone of [[method-performance]] evaluation and routine [[quality-control]].

## Key Points

- **Precision** (repeatability/reproducibility) and **accuracy** (closeness to true value) are the fundamental performance metrics quantified statistically.
- **Regression analysis** (e.g., Deming, Passing-Bablok) compares a new method against a reference method, quantifying bias and proportional error.
- **Bland-Altman analysis** assesses agreement between two methods, plotting differences against means.
- **ROC analysis** evaluates [[diagnostic-accuracy]], quantifying sensitivity and specificity across decision thresholds (AUC).
- Statistical methods underpin [[laboratory-verification]] and [[laboratory-validation]] studies, including reference interval establishment and determination of analytical measurement range.
- **Control chart statistics** (Levey-Jennings, Westgard rules) apply these principles to routine QC monitoring.

## Common Methods

| Method | Application |
|---|---|
| Descriptive statistics | Mean, SD, CV for QC data |
| Regression (Deming/Passing-Bablok) | Method comparison |
| Bland-Altman | Method agreement |
| ROC / AUC | [[diagnostic-accuracy]] |
| ANOVA / components of variance | Precision evaluation |
| Tolerance / prediction intervals | Reference range estimation |

## Relationship to Quality Systems

Statistical analysis is the quantitative engine connecting several laboratory quality activities: it provides the evidence for [[method-performance]] claims, the data for [[quality-control]] decisions, and the analytical foundation for [[laboratory-verification]] and [[laboratory-validation]] protocols.
