# qPCR

## Overview

Quantitative real-time polymerase chain reaction (qPCR) - a molecular biology technique for amplifying and quantifying DNA in real-time.

## Applications

- **Pathogen detection:** Viral and bacterial load quantification
- **Gene expression:** mRNA quantification
- **Genotyping:** SNP detection
- **Clinical diagnostics:** Viral load monitoring, pathogen identification

## Technical Aspects

- **Ct value:** Cycle threshold - the cycle number at which fluorescence exceeds background
- **Internal controls:** RNase P, extraction controls
- **Multiplex PCR:** Simultaneous detection of multiple targets
- **Probe chemistry:** TaqMan, SYBR Green
