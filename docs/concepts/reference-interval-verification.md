# Reference Interval Verification

**Reference interval verification** confirms that a published reference interval is appropriate for the laboratory's patient population.

## Verification (FDA-approved tests)
- Test 20 reference individuals
- ≥ 90% (18/20) within published interval
- Document outliers

## Establishment (LDTs)
- Test minimum 120 reference individuals
- Non-parametric: 2.5th-97.5th percentiles
- Partition by age, sex, ethnicity if significant
