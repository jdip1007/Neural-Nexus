# Performance Characteristics

## Overview

Metrics used to evaluate and validate laboratory methods and diagnostic tests.

## Analytical Performance

- **Sensitivity:** Ability to detect low concentrations
- **Specificity:** Ability to detect only the target analyte
- **Limit of Detection (LOD):** Lowest detectable concentration
- **Limit of Quantification (LOQ):** Lowest reliably quantifiable concentration
- **Linear Range:** Concentration range with linear response
- **Precision:** Repeatability and reproducibility
- **Accuracy:** Closeness to true value
- **Reference interval:** Normal value range

## Clinical Performance

- **Clinical Sensitivity:** True positive rate in disease population
- **Clinical Specificity:** True negative rate in healthy population
- **Positive Predictive Value (PPV):** Probability disease given positive test
- **Negative Predictive Value (NPV):** Probability no disease given negative test
- **Diagnostic accuracy:** Overall correctness
