# qPCR Performance Characteristics

## Overview

Performance metrics for real-time PCR (quantitative PCR) assays in clinical molecular diagnostics.

## Key Metrics

- **Analytical Sensitivity (LOD):** Limit of detection
- **Clinical Sensitivity:** True positive rate in clinical samples
- **Clinical Specificity:** True negative rate
- **Positive Predictive Value (PPV)**
- **Negative Predictive Value (NPV)**
- **Ct Value Precision:** Reproducibility of cycle threshold values
- **Dynamic Range:** Linear quantification range
