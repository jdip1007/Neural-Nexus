# Change Control

**Change control** is the systematic process for managing modifications to laboratory test methods, equipment, software, or procedures to ensure continued performance and compliance.

## Key Elements

- Document all changes to method, reagents, software, or equipment
- Assess impact on performance characteristics
- Perform bridging studies or re-verification if needed
- Update SOPs, documentation, and training
- Obtain approval before implementing changes

## When Change Control Triggers Re-verification

- New reagent lot with different performance
- Software algorithm changes
- New instrument platform
- Modified specimen type
- Extended reportable range
