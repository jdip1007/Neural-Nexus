# IQ Test Validity in ASD

**Definition:** The concern that standard intelligence quotient tests may not validly measure cognitive capacity in autistic individuals because test demands overlap with ASD core deficits.

## Mechanism

Standard IQ tests (Wechsler Intelligence Scales, Stanford-Binet) rely on subtests that demand:
- **Verbal comprehension:** Understanding and producing spoken language (impaired in many ASD individuals)
- **Processing speed:** Rapid information processing under time pressure (often slower in ASD)
- **Social reasoning:** Understanding social contexts embedded in test items (core ASD deficit)
- **Cognitive flexibility:** Switching between task demands (rigidity is an ASD feature)

These demands conflate ASD symptomatology with cognitive ability, potentially depressing IQ scores below true capacity.

## Alternative Approaches

- **Raven's Progressive Matrices:** Minimizes verbal and social demands; often yields higher scores in ASD than Wechsler scales
- **Leiter International Performance Scale:** Nonvertest; reduced language/cultural loading
- **Adaptive behavior measures:** Focus on functional skills rather than abstract reasoning
- **Discrepancy analysis:** Comparing verbal vs nonverbal IQ profiles to identify test-related depression

## Clinical Significance

- Underestimated IQ leads to inappropriate support placement (too restrictive)
- IQ scores may improve with accommodated testing conditions
- The gap between Wechsler and Raven's scores in ASD can be 20+ points
- IQ should be interpreted as "performance under standard conditions" not "fixed cognitive capacity"
