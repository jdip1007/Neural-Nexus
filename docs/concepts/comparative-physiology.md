# Comparative Physiology

**Comparative physiology** studies the functional similarities and differences across species, with a focus on how physiological processes scale with body size and adapt to environmental conditions.

## Key Areas

- **Metabolic scaling**: How metabolic rate changes with body mass
- **Allometric relationships**: Non-proportional scaling of body features
- **Thermoregulation**: How heat production scales with size
- **Cardiovascular scaling**: Heart rate, blood pressure, aortic size
- **Life history theory**: Lifespan, growth rate, reproduction trade-offs
