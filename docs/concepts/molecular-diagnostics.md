# Molecular Diagnostics

**Molecular diagnostics** encompasses laboratory tests that detect and analyze nucleic acids (DNA, RNA) for clinical purposes including infectious disease, oncology, genetics, and pharmacogenomics.

## Test Categories

- **PCR-based**: Qualitative and quantitative PCR
- **NGS panels**: Targeted gene panels, whole exome/genome
- **Microarrays**: SNP arrays, expression arrays
- **In situ hybridization**: FISH, CISH

## Validation Considerations

Molecular tests often require specialized validation including:
- Inhibition testing
- Cross-reactivity with related sequences
- Limit of detection at clinical thresholds
- Bioinformatics pipeline validation
