# Retro Computing

Retro computing explores vintage computers, legacy systems, and computing technology from past decades (1970s-1990s).

## Key Areas

- **1980s Computing**: Early personal computers, 8-bit systems, BASIC programming
- **1990s Technology**: Windows 9x era, early internet, dial-up modems
- **Vintage Hardware**: Old disk drives, CRT monitors, mechanical keyboards
- **Preservation**: Software archaeology, hardware restoration, emulation
