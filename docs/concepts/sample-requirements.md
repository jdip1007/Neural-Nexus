# Sample Requirements

**Sample requirements** define the types, numbers, volumes, and handling conditions for specimens used in laboratory verification and validation studies.

## Key Parameters

- **Sample types**: Patient specimens, reference materials, proficiency testing samples, pooled specimens
- **Sample numbers**: Precision (20+ replicates), accuracy (40+ specimens), LoD (20+ replicates)
- **Sample volume**: 2-3 mL minimum per specimen, plus dead volume
- **Storage conditions**: Room temp, refrigerated, frozen stability requirements
