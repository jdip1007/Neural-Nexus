# APHL Verification and Validation Toolkit

Complete comprehensive toolkit for clinical laboratory verification and validation studies, published by the Association of Public Health Laboratories (APHL) to assist laboratories in meeting CLIA regulatory requirements.

## Document Overview

**Title:** Laboratory Test Verification and Validation Toolkit
**Publisher:** Association of Public Health Laboratories (APHL)
**Publication Date:** March 2024
**Pages:** 37 (complete toolkit)
**Sections:** 8 main sections + reference materials

## Purpose and Scope

The toolkit helps clinical laboratories:
1. Determine the difference between verification and validation
2. Understand when each process should be performed
3. Plan, implement, and analyze verification/validation studies
4. Meet CLIA regulatory requirements
5. Ensure quality of test results before patient testing

### Section 3: Obtaining Appropriate Test Samples
**Content:** Sample types, numbers, and volume requirements

**Sample Types:**
- Patient specimens (preferred for verification)
- Reference materials
- Proficiency testing samples
- Pooled specimens

**Sample Numbers:**
- Precision: Minimum 20 replicates
- Accuracy: Minimum 40 specimens
- LoD: Minimum 20 replicates at low concentration
- Reference intervals: 20 (verify) or 120 (establish)

**Volume Requirements:**
- Minimum 2-3 mL per specimen
- Additional volume for repeat testing
- Account for aliquot needs

### Section 4: Qualitative Assays
**Content:** Performance characteristics for qualitative (yes/no) tests

**Characteristics Covered:**
1. Accuracy (Method Comparison)
   - Percent agreement ≥ 95%
   - Kappa statistic ≥ 0.75
   - Sensitivity, specificity, PPV, NPV

2. Precision (Repeatability)
   - Within-run agreement ≥ 95%
   - Between-run agreement ≥ 90%

3. Analytical Sensitivity (LoD)
   - Probit analysis method
   - ≥ 19/20 (95%) detection at LoD

4. Analytical Specificity
   - Cross-reactivity testing
   - Interference testing
   - No false positives from unrelated substances

5. Reportable Range
   - Confirm manufacturer's stated range
   - Test low, mid, high concentrations

6. Reference Range
   - Verify with 20 reference individuals
   - Confirm ≥ 90% within published range

### Section 5: Quantitative Assays
**Content:** Performance characteristics for quantitative (numerical) tests

**Additional Characteristics:**
- Calibration verification (every 6 months)
- Calibration curve evaluation (r ≥ 0.99)
- Limit of Quantitation (LoQ)
- Weighted regression (if needed)

**Acceptance Criteria:**
- Bias within ±10%
- CV: ≤ 5% (within-run), ≤ 7.5% (between-run), ≤ 10% (total)
- LoD: 95% detection probability
- LoQ: CV ≤ 20%

**Statistical Methods:**
- Paired t-test, Deming regression
- Bland-Altman plot
- Passing-Bablok regression
- ANOVA for precision
- Probit analysis for LoD

### Section 6: Related Processes
**Content:** Ongoing quality management activities

**Topics:**
1. Sample/Analyte Stability
   - Room temp, refrigerated, frozen stability
   - Freeze-thaw cycles
   - Acceptance: bias within ±10%

2. Bridging Studies
   - Modifications requiring new validation
   - Sample comparison before/after change
   - Acceptance: bias within ±10%, r ≥ 0.95

3. Instrumentation V&V
   - Installation Qualification (IQ)
   - Operational Qualification (OQ)
   - Performance Qualification (PQ)

4. Reagent Lot-to-Lot Comparison
   - Test 20-40 samples with both lots
   - Acceptance: bias within ±10%

5. Software Upgrades
   - Impact assessment required
   - Verification after major upgrades
   - Algorithm changes may require re-validation

### Section 7: Safety Considerations and Risk Assessments
**Content:** Laboratory safety and risk management

**Risk Assessment Process:**
1. Hazard identification
2. Risk analysis (likelihood × severity)
3. Risk evaluation against criteria
4. Risk mitigation (engineering, administrative, PPE)
5. Monitoring and review (at least annually)

**Risk Categories:**
- Biological risks (infectious agents, biosafety level)
- Chemical risks (hazardous reagents, SDS)
- Physical risks (electrical, mechanical, thermal)
- Ergonomic risks (repetitive motion, heavy lifting)

### Section 8: Cost Analysis and Budget
**Content:** Planning V&V project costs

**Cost Categories:**
1. Labor Costs
   - 40-88 hours per V&V project
   - Personnel: Director, Supervisor, Technologist, Quality Manager

2. Materials Costs
   - Test reagents
   - QC materials
   - Reference materials
   - Supplies

3. Site Preparation Costs
   - Facility modifications
   - Infrastructure needs

4. Maintenance Costs (ongoing)
   - QC materials: $5,000-15,000/year per assay
   - Reagents: $10,000-50,000/year per assay
   - PT participation: $500-2,000 per event
   - Training: $1,000-5,000 per staff member

## Best Practices Summary

### Before V&V
1. Clearly define test method and intended use
2. Determine verification vs validation
3. Select team and assign responsibilities
4. Establish timeline and budget
5. Obtain necessary approvals

### During V&V
1. Follow protocol strictly
2. Document all activities
3. Track deviations
4. Perform statistical analysis properly
5. Compare to acceptance criteria

### After V&V
1. Prepare comprehensive report
2. Obtain final approvals
3. Update procedures
4. Train staff
5. Implement QC program

### Common Pitfalls
- Insufficient sample size
- Inadequate sample range
- Wrong statistical methods
- Not following protocol
- Incomplete documentation
- Missing acceptance criteria
- No ongoing QC plan
