# Reliable Isn't Always Better: TCP vs UDP

## Overview

This video explores the fundamental differences between TCP (Transmission Control Protocol) and UDP (User Datagram Protocol) - two essential protocols that power modern internet communications.

## Key Concepts

- **TCP**: Connection-oriented, reliable, ordered delivery
- **UDP**: Connectionless, best-effort, faster but less reliable
- **Use Cases**: TCP for web browsing, UDP for video streaming
- **Performance**: UDP has lower overhead but no guarantees

## Technical Details

### TCP Characteristics
- **Reliability**: Guaranteed delivery with acknowledgments
- **Ordering**: Data arrives in the same order sent
- **Flow Control**: Prevents overwhelming the receiver
- **Congestion Control**: Manages network traffic

### UDP Characteristics  
- **Speed**: Lower latency and higher throughput
- **Simplicity**: Minimal protocol overhead
- **Unreliable**: No guarantees on delivery or order
- **Broadcast**: Supports one-to-many communication

## Applications

### TCP Use Cases
- Web browsing (HTTP/HTTPS)
- File transfers (FTP, SFTP)
- Email (SMTP, POP3)
- Database connections

### UDP Use Cases
- Video streaming
- Online gaming
- DNS queries
- VoIP calls

## Conclusion

Understanding when to use TCP vs UDP is crucial for network design and application development. The choice depends on whether you prioritize reliability (TCP) or speed/efficiency (UDP).
